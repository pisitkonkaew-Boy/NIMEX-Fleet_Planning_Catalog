# NIMEX Fleet Planning Catalog

แคตตาล็อกรถสำหรับวางแผนกองรถ (ภาพรถ 4 ด้าน ราย DC และรายทะเบียน) หน้าตาตาม NIMEX Design Kit

- repo นี้ไม่มีข้อมูลรถ ผู้ใช้กด "นำเข้า XLSX" แล้วข้อมูลกับรูปจะเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
- การคำนวณและการอ่านไฟล์เหมือนเดิมทุกอย่าง (ปรับเฉพาะหน้าตา)
- ห้ามนำไฟล์ XLSX ข้อมูลจริงขึ้น repo นี้ เพราะ repo เป็นสาธารณะ
